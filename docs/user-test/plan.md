# 사용자 테스트 계획 (시각장애인 대상, 1차)

> 초안입니다. 실제 진행 전 소속 기관의 연구윤리(IRB 등) 검토 필요 여부를 확인하세요. 수치 목표는 PRD §12의 가설이며 결과가 아닙니다.

## 목적
1. 이음으로 웹 과제를 **스스로** 끝낼 수 있는지(과업 성공률)
2. 평소 쓰는 화면낭독기만 쓸 때와 비교해 시간·도움 요청·부담이 어떻게 다른지
3. 어디서 막히는지(되묻기가 많은 곳, 오해한 명령, 너무 긴 안내)

## 참여자
- 성인 시각장애인 3~5명(전맹·저시력 섞어서), 화면낭독기 숙련도 다양하게
- 모집: 지역 복지관·시각장애인 단체 협조. 사례비·이동 지원 사전 안내
- 제외: 실제 개인정보 입력이 필요한 과제는 하지 않음(합성 정보만)

## 환경
- 맥 또는 윈도 노트북 1대, 외장 스피커 또는 이어폰(끼어들기 확인을 위해 둘 다 시도)
- 실행: `npm run desktop`(데스크톱 앱 — 켜면 바로 동의 안내, Enter=동의, Cmd/Ctrl+Shift+Space=지금 말하기). 처음 한 번은 macOS 마이크 허용 창이 뜨므로 진행자가 미리 허용해 둔다.
- `.env`: `BROWSER_MODE=chrome`, `REQUIRE_CONSENT=true`, OpenAI 키 설정
- 비교 조건: 참여자가 평소 쓰는 화면낭독기(NVDA/센스리더/VoiceOver)만 쓰는 조건
- 순서 효과를 줄이려고 참여자마다 조건 순서를 바꾼다(A→B / B→A)

## 진행(약 60분)
| 시간 | 내용 |
|---|---|
| 5분 | 소개, 동의서(소리로 읽어 드리고 서명 또는 녹음 동의) |
| 10분 | **사전 인터뷰(아이디어 검증, 아래 질문)** — 과제 전에 한다(이음을 보기 전의 실제 경험을 듣기 위해) |
| 5분 | 연습: "네이버 열어줘", "멈춰", 띵 소리·스페이스·끼어들기 체험 |
| 30분 | 과제(아래 tasks.md), 과제당 최대 5분, 막히면 "도움" 요청 가능 |
| 10분 | 설문(SUS 한국어판 10문항 + 부담감 1~7점) |
| 5분 | 인터뷰: 가장 좋았던 점/답답했던 점/믿을 수 있었는지 |

## 측정
| 지표 | 정의 | 기록 방법 |
|---|---|---|
| 과업 성공 | 도움 없이 목표 달성(성공/부분/실패) | 진행자 기록지 |
| 소요 시간 | 과제 시작 발화 ~ 완료 | 기록지 + 서버 이벤트 |
| 도움 요청 | 진행자 개입 횟수 | 기록지 |
| 되묻기·오해 | 이음이 되묻거나 엉뚱한 일을 한 횟수 | 기록지 + `/api/events` |
| 응답 지연 | 서버 처리 시간 | `GET /api/events`(발화·입력값 없음) |
| 사용성 | SUS 점수(0~100) | 설문 |
| 신뢰 | "이음이 무엇을 하는지 알 수 있었다" 1~7 | 설문 |

## 데이터 처리
- 화면·음성 녹음은 하지 않는 것이 기본. 녹음이 필요하면 별도 동의를 받고 분석 후 삭제
- 서버 로그는 비식별 이벤트(액션 종류·성공·지연·오류 코드)만 저장 — 발화 원문·입력값 없음
- 결과 보고는 참여자를 P1~P5로만 표기

## 안전
- 실제 신청·제출·로그인은 과제에 넣지 않는다(연습용 모의 신청서와 읽기 과제만)
- 참여자가 원하면 언제든 중단, "멈춰"가 동작하지 않으면 진행자가 즉시 브라우저를 닫는다

## 사전 인터뷰 질문(아이디어 검증)
목표: "보이지 않아서 공공 사이트에서 혼자 끝내지 못한 일"의 실제 사례를 모은다. 이음 이야기는 하지 않는다.
1. 최근 1년 동안 인터넷으로 하려다가 **포기했거나 남에게 부탁한** 일이 있으세요? 무엇이었나요?
2. 그때 정확히 **어디서 막혔나요?** (팝업, 신청서 칸, 본인인증 창, 첨부 문서, 이미지 글자, 보안 프로그램 설치 등)
3. 결국 어떻게 해결하셨나요? 누구에게 부탁했고 시간은 얼마나 걸렸나요?
4. 정부24·복지로·홈택스·은행·병원 예약 중 **혼자 끝까지 해 본 것**은? 안 되는 것은?
5. 다른 사람이나 프로그램이 대신 입력해 줄 때 **가장 걱정되는 점**은? (잘못 입력, 개인정보, 모르게 제출 등)
6. "여기서부터는 직접 하셔야 해요"라고 넘겨받는다면, **어떤 순간에 넘겨받는 게 괜찮으세요?**

기록: 사례마다 사이트·막힌 지점·해결 방법·걸린 시간·도움받은 사람을 `record-sheet.csv`의 notes 또는 별도 메모에 남긴다(이름·개인정보 없이).
