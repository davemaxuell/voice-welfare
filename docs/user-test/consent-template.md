# 연구 참여 동의서 (양식 초안)

> 양식 초안입니다. 소속 기관의 연구윤리 지침에 맞게 검토·수정 후 사용하세요. 참여자에게는 소리 내어 읽어 드리고, 점자·큰 글자·음성 파일 등 원하는 형태로 제공합니다.

**연구 제목:** 음성 기반 웹·복지 도우미(청음) 사용성 평가
**연구자:** (이름, 소속, 연락처)

1. **무엇을 하나요?** 약 60분 동안 노트북으로 몇 가지 웹 과제(뉴스 듣기, 날씨 알아보기, 연습용 신청서 작성 등)를 해 보고, 소감을 말씀해 주십니다.
2. **실제 신청이 되나요?** 아니요. 신청서는 연습용이며 어디에도 접수되지 않습니다. 실제 개인정보는 입력하지 않고 예시 정보만 씁니다.
3. **어떤 정보가 기록되나요?** 과제 성공 여부, 걸린 시간, 설문 답변. 프로그램은 명령 종류·성공 여부·처리 시간만 기록하고, 말씀하신 내용 원문은 저장하지 않습니다. 말씀하신 음성은 받아쓰기를 위해 외부 인공지능 서비스(OpenAI)로 전송됩니다. (로컬 받아쓰기 `STT_PROVIDER=local`로 진행할 때는 대신: "한국어 음성은 이 노트북 안에서 글자로 바뀌며 밖으로 전송되지 않습니다. 영어·중국어·일본어 음성은 OpenAI로 전송됩니다.")
4. **녹음하나요?** 기본적으로 하지 않습니다. 녹음이 필요하면 따로 여쭙고, 동의하실 때만 합니다. (녹음 동의: 예 / 아니요)
5. **언제든 그만둘 수 있나요?** 네. 이유 없이 언제든 중단할 수 있고 불이익은 없습니다.
6. **결과는 어떻게 쓰이나요?** 이름 없이(P1, P2처럼) 정리하여 서비스 개선과 공모전 보고서에 씁니다.
7. **사례:** (금액·방법)
