# 과제 카드 (진행자가 소리 내어 읽어 줍니다)

목표만 알려 주고 말하는 방법은 알려 주지 않습니다. 과제당 최대 5분.

| # | 과제(읽어 줄 문장) | 성공 기준 | 보는 것 |
|---|---|---|---|
| T1 | "인터넷을 켜고 네이버에 들어가 보세요." | 네이버가 열림 | 시작·크롬 켜기 |
| T2 | "오늘 주요 뉴스 하나를 들어 보세요." | 뉴스 제목·내용 1개 이상 들음 | 목표 수행(자율), 안내 길이 |
| T3 | "오늘 날씨를 알아보세요." | 기온이나 날씨를 들음 | 실시간 질문 |
| T4 | "기초연금을 언제부터 받을 수 있는지 알아보세요." | 나이 기준을 들음 | 근거 답변, 되묻기 |
| T5 | "그 제도를 어디서 신청하는지 물어보세요." | 신청 경로를 들음 | 이어지는 질문(맥락) |
| T6 | "연습용 장애인연금 신청서를 열고 이름과 주소를 넣어 보세요. 이름은 김하늘, 주소는 부산광역시 예시구 예시로 10입니다." | 두 칸이 바르게 입력됨 | 여러 명령, 확인 |
| T7 | "넣은 주소를 다시 들어 보고, 20번지로 바꿔 보세요." | 주소가 …로 20으로 바뀜 | 읽기·수정 |
| T8 | "끝까지 진행해서 모의 접수해 보세요." | 모의 접수번호를 들음 | 승인 흐름, 단계 이동 |
| T9 | "청음이 말하는 도중에 끊고 다른 것을 물어보세요." | 끊고 새 질문이 처리됨 | 끼어들기·스페이스 |
| T10 | "지금 하던 것을 멈추게 해 보세요." | 멈춤 확인 | 멈춤 |
| T11 | "본인 조건으로 받을 수 있는 복지가 있는지 찾아 보세요. (실제 정보 대신 예시: 68세, 심한 장애, 차상위, 서울)" | 제도 3개 이상 듣고, 하나의 자격 점검을 들음 | 맞춤 찾기(부가 기능), 질문 흐름 |
| T12 | "그 제도의 공식 안내 페이지를 열고, 신청하려면 무엇이 필요한지 들어 보세요." | 서식·문의처를 듣고 페이지가 열림 | B→A 인계, 넘겨주는 지점 안내 |

화면낭독기 단독 조건에서는 T1~T5, T8을 같은 방식으로 진행합니다(T6~T7은 모의 신청서에서 직접 입력).
