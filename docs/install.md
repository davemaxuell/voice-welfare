# 청음 설치와 첫 사용

## Windows에 설치하기

1. Windows x64 PC에서 받은 `Cheongeum-Setup-버전.exe`를 엽니다. 이 설치본에는 Chromium과 앱을 실행하는 Node 런타임이 포함됩니다. 서명되지 않은 로컬 빌드에서는 Windows가 게시자 확인 안내를 표시할 수 있습니다.
2. 설치 폴더를 고르고 **관리자 권한** 화면에서 청음 바로 가기에 관리자 권한을 허용할지 선택한 뒤 **설치**를 누릅니다.
3. 시작 메뉴에서 **청음**을 엽니다. 첫 실행에 **청음 처음 설정**이 열리고 녹음된 목소리가 단계마다 읽어 줍니다. 숫자 키, Enter, Esc(이전 단계)로 답하세요.
   - 대화 언어를 고른 뒤 **지금 누가 설정하는지** 고릅니다. 사용하실 분 본인은 1번, 가족이나 복지관 직원은 2번입니다.
   - OpenAI API 키를 붙여 넣고 Enter를 누릅니다. 청음이 키를 한 번 확인합니다. 키가 없으면 설정을 마칠 수 없습니다.
   - 이 컴퓨터를 혼자 쓰는지 여러 사람이 쓰는지 고릅니다. 도와주는 분은 이어서 평소 쓰는 크롬 사용, 컴퓨터를 켤 때 청음 켜기, 보호자 연락처(개인 PC)를 정한 뒤 사용하실 분께 넘겨 주세요.
   - 사용하실 분이 청음 목소리로 소리를 확인하고 말 빠르기를 고릅니다.
   중간에 앱을 닫으면 다음 실행에서 소리 확인부터 이어 갑니다.
4. 음성 이용 안내를 듣고 동의한 뒤 “정부24에서 주민등록등본 발급 방법 찾아줘”, “장학재단에서 국가장학금 신청 기간 알려줘”, “복지로 열어줘”처럼 말씀하세요. 직접 입력하려면 대화 창을 여세요.

**대화 시작**을 누르면 등록한 키로 GPT-Live와 음성 대화를 시작합니다. 청음이 기관 조회나 화면 조작을 요청받으면 해당 발화를 앱으로 보내고 확인된 결과를 읽어 줍니다. **녹음 파일 받아쓰기**에서는 파일을 직접 골라 전송하고 받은 글을 읽거나 복사할 수 있습니다. OpenAI 키는 이 PC의 OS 자격 증명으로 암호화해 보관합니다. 안내 속도는 기본 1.35배입니다. 시작 안내는 처음 한 번 자동 재생됩니다. 다음 실행부터는 바로 동의 여부를 고르세요. “시작 안내 다시 읽어줘”라고 말하거나 동의 화면에서 **안내 전문 듣기**를 누르면 다시 들을 수 있습니다.

청음은 대화 중에 보고 있는 기관과 업무를 기억합니다. 국가장학금에 대해 물은 뒤 “그럼 서류는?”처럼 이어서 물어보세요. **이용 설정**에서 **나만 쓰는 개인 PC**를 고르고 **다음 이용에도 마지막 기관과 업무 이름 기억하기**를 켜면 앱을 다시 열어도 그 업무를 이어서 물을 수 있습니다. 끄면 저장된 업무 이름을 지웁니다. 공용 기기나 사용 방식을 고르지 않은 기기에서는 업무 이름을 다음 실행에 넘기지 않습니다. 설정은 대화 중에도 바꿀 수 있습니다.

기관이나 업무 이름이 불분명하게 들리면 청음이 들은 내용을 확인합니다. 제안이 맞으면 “네”, 다르면 원하는 업무 이름을 말씀하세요. 등본과 초본처럼 후보가 둘이면 번호로도 고를 수 있습니다.

바탕화면 어느 모서리에 두어도 말풍선은 청음의 머리 바로 위에 떠요. 짧은 알림은 잠시 후 사라지고, 선택이 필요한 말풍선은 답할 때까지 남아요. **Ctrl+Shift+K**를 누르면 말풍선의 선택지로 이동하고, 청음을 누르면 대화 전문을 읽을 수 있어요.

**멈춰**를 누르면 청음이 눈을 감고 새근새근 숨을 쉬어요. 캐릭터를 누르거나 **Ctrl+Shift+Space**로 말을 시작하거나 대화 창에서 글을 보내면 바로 깨어나요. 움직임 줄이기를 사용하면 눈을 감은 그림으로 쉬어요.

| 하고 싶은 일 | 조작 |
| --- | --- |
| 다른 창을 보면서 말하기 | **Ctrl+Shift+Space** |
| 아바타의 선택지에 키보드 초점 두기 | **Ctrl+Shift+K** |
| 대화 창 다시 열기 | 캐릭터를 누르거나 시작 메뉴에서 **청음** 다시 실행 |
| 마이크와 스피커 확인 | 대화 창의 **음성 설정 → 마이크 확인** 또는 **소리 확인** |
| 앱 완전히 종료하기 | 작업 표시줄 알림 영역의 청음 아이콘을 오른쪽 클릭한 뒤 **청음 종료** |
| 새 버전 확인 | 트레이의 **업데이트 확인…** |
| 제거 | Windows **설정 → 앱 → 설치된 앱 → 청음 → 제거** |

## 자료 조사와 저장한 메모

개인 PC로 설정하고 대화에 동의하면 **자료 조사와 저장한 메모**를 사용할 수 있습니다. “국가장학금 서류를 나중에 볼 수 있게 조사해 줘”처럼 말하거나 글을 쓰고, 청음이 읽어 주는 질문을 확인해 **자료 조사 승인**을 누르세요. 이 패널에서 직접 질문을 작성할 수도 있습니다. 청음은 별도 브라우저에서 공개 자료를 확인합니다. 결과와 출처를 보거나, 진행 중인 조사를 중단하거나, 끝난 결과를 삭제할 수 있습니다. 앱을 완전히 종료하면 조사가 멈추고 다음 실행에서 이어집니다.

다음 대화에서도 사용할 선호 사항은 메모란에 직접 적고 메모 저장 동의를 선택하세요. 청음은 메모와 관련 질문을 임베딩해 필요한 메모만 참고합니다. 같은 패널에서 메모를 찾고 삭제할 수 있습니다. 음성 녹음은 조사나 메모에 저장하지 않습니다.

기본 저장소는 Windows 계정의 `~/.cheongeum/workflows.sqlite3`입니다. 서버를 운영할 때는 pgvector 0.5 이상이 설치된 PostgreSQL을 준비하고 `CHEONGEUM_DATABASE_URL`에 연결 문자열을 설정할 수 있습니다. DB 계정에는 최초 생성 시 테이블과 인덱스를 만들 권한이 필요합니다. 관리자가 먼저 `CREATE EXTENSION vector`를 실행하거나 DB 계정에 해당 권한을 부여하세요. 소스에서 실행할 때는 저장소 루트의 `npm ci`가 PostgreSQL 드라이버(`pg`)도 설치합니다. 기존 SQLite 조사와 메모는 해당 파일에 보관되며 DB 연결 변경 시 자동으로 복사되지 않습니다.

## 마이크, 스피커, 관리자 권한

동의 후 청음 대화 창에서 선택한 마이크를 사용합니다. **마이크 확인**은 연결을 잠깐 확인합니다. **소리 확인**을 누르면 Windows의 출력 장치로 안내가 재생됩니다. 장치를 바꾸거나 마이크 접근을 허용하려면 트레이의 **Windows 마이크 권한 설정**, **Windows 스피커 설정**을 여세요.

설치할 때 **청음 바로 가기를 관리자 권한으로 실행**을 선택하면 시작 메뉴와 바탕 화면의 **청음** 바로 가기가 Windows 사용자 계정 컨트롤(UAC) 승인을 요청합니다. 표준 사용자 계정은 관리자 자격 증명이 필요합니다. 선택하지 않으면 일반 권한으로 실행합니다. 두 모드에서 마이크와 스피커를 사용할 수 있습니다.

## 업데이트 받기

청음은 실행 후, 그리고 실행 중 하루에 한 번 GitHub의 공개 정식 릴리스를 확인합니다. 새 버전 안내에서 **다운로드** 또는 **나중에**를 선택하세요. 다운로드가 끝나면 작업을 마치고 **지금 설치하고 다시 시작**을 누르세요. **나중에**를 선택한 뒤에는 트레이에서 다시 열 수 있습니다. 업데이트는 설치 때 선택한 관리자 설정을 유지합니다.

## 서비스 연결하기

청음은 저장된 복지 자료와 규칙으로 질문에 답할 수 있습니다. 한국어를 포함한 모든 언어의 음성 대화와 받아쓰기에는 인증된 음성 API가 필요합니다. 기기에 포함된 개인정보 인식 모델은 입력에서 민감한 글을 찾는 데 사용합니다. 최신 복지 API 조회와 실제 문자 발송에는 각 서비스의 설정이 필요합니다.

이미 개발용 `.env`가 있다면 청음의 트레이 메뉴에서 **기존 서비스 설정 가져오기…**를 선택하고 해당 파일을 고르세요. 청음을 완전히 종료하고 다시 열면 적용됩니다.

직접 설정하려면 **서비스 설정 폴더 열기**를 선택하고 그 폴더에 UTF-8 텍스트 파일 `settings.env`를 저장하세요. 직접 등록한 키를 우선 사용합니다. 환경 파일에서는 `OPENAI_API_KEY` 또는 `VOICE_API_KEY`로 음성을 연결할 수 있습니다. 키가 들어 있는 개인 설정 파일은 본인의 PC에 보관하세요.

## 설치 파일 만들기

빌드할 대상과 같은 운영체제·CPU를 사용하는 컴퓨터에서 Node.js 24 이상을 준비하세요. Windows x64 설치 파일은 Windows x64에서 다음과 같이 만듭니다. 명령은 모두 저장소 루트에서 실행하세요.

```sh
npm ci
npm run setup-models
npm run dist:desktop
npm run test:desktop-packaged
npm run test:desktop-release
```

`npm run setup-models`는 개인정보 탐지용 ONNX 모델을 내려받아 로컬 추론을 확인합니다. 패키징할 때 이 모델과 Chromium을 설치본에 복사합니다. `apps/desktop/dist/`에 `Cheongeum-Setup-버전.exe`, `.exe.blockmap`, `latest.yml`이 생깁니다. 버전 번호는 `apps/desktop/package.json`에서 확인할 수 있습니다.

`test:desktop-packaged`는 패키지 안의 앱과 서비스를, `test:desktop-release`는 설치 파일과 업데이트 자료를 검사합니다. 새 Windows 계정에 직접 설치해 실제 마이크와 화면 읽기 프로그램으로 확인하는 절차가 별도로 남아 있습니다.

macOS용 DMG는 대상 Mac에서 같은 `npm ci`, `npm run setup-models`, `npm run dist:desktop` 순서로 빌드합니다. 해당 Mac의 CPU에 맞는 Electron과 Chromium이 포함됩니다.

## GitHub에 새 버전 배포하기

`apps/desktop/package.json`의 버전을 올려 커밋하고 같은 버전의 태그(예: 버전 `0.4.5`이면 `v0.4.5`)를 푸시하면 `.github/workflows/release-windows.yml`이 Windows 설치 파일을 빌드합니다. 패키지와 업데이트 검사를 통과하면 설치 파일, 블록맵, `latest.yml`을 공개 릴리스에 올립니다.

수동 배포도 가능합니다. 같은 버전의 공개 정식 릴리스에 `Cheongeum-Setup-버전.exe`, `Cheongeum-Setup-버전.exe.blockmap`, `latest.yml`을 파일 이름 그대로 올리세요. 기존 사용자는 현재 설치된 버전보다 높은 정식 버전이 공개되면 업데이트를 선택할 수 있습니다.
