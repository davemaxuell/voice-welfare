# GPT-Live-1.1 For Every Spoken Sentence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every sentence the app speaks is produced by `gpt-live-1.1`, including the conversation and the sentence the app itself wrote.

**Architecture:** The conversation WebRTC session already speaks with the voice model in `STACK.voice`; that id becomes `gpt-live-1.1`. `gpt-live-1.1` cannot call `POST /v1/audio/speech` ([model page](https://developers.openai.com/api/docs/models/gpt-live-1.1)). Scripted sentences (the old `gpt-4o-mini-tts` path: dictate and text replies, exact conversation replies, first-run stage 2, the sound check) open a short primary Live WebSocket, ask `gpt-live-1.1` to say that text exactly, and return the PCM as a WAV the current player already decodes. Listening stays on `gpt-live-transcribe` and `gpt-transcribe`.

**Tech Stack:** TypeScript, the existing `connectSocket` Live WebSocket, Vitest unit project, Hono `/api/audio/speak`.

**Spec:** This plan is the spec. The request is: change the voice model from GPT-Live-1 (`gpt-live-1`, called 1.0 in the request) to `gpt-live-1.1`, speak the app's own final sentence with `gpt-live-1.1` as well, and use no other TTS model for audio the app says.

## Global Constraints

- The only speech model id is `gpt-live-1.1`. `TTS_MODEL` and `VOICE_LIVE_MODEL` do not select a different speech model. `VOICE_LIVE_MODEL=gpt-live-transcribe` still means "no conversation session", which is the existing opt-out, not a second voice.
- No production path calls `POST /v1/audio/speech` or sends `gpt-4o-mini-tts`. A non-OpenAI `VOICE_BASE_URL` does not fall back to that endpoint; speech there is unsupported.
- File transcription stays `gpt-transcribe`. One-shot microphone transcription stays `gpt-live-transcribe`. Sound-cue tones and ogg files are not speech and stay.
- Voice name stays the configured `TTS_VOICE`, default `coral`, on both the conversation session and the reader. Pace stays the saved speed times the request pace, clamped to 0.25–4, spoken as an instruction because Live has no `speed` field. Do not also speed the playback buffer.
- A turn with `localSpeechOnly` contains a secret the history redacts. That sentence is not sent to `gpt-live-1.1` and is not given to the conversation model as commentary. `speakOnDevice` (the operating-system voice) keeps speaking it, so a person who cannot see the screen still hears it. That path is the exception to "no other TTS", and it exists so the secret is not uploaded.
- Shipped first-run mp3 clips stay until someone with a key runs `node scripts/record-setup-clips.ts --force`. The script already calls `createVoiceProviders`, so the next recording uses the reader. This plan does not re-record them.
- User-facing copy and code comments stay Korean. Do not add a comment that only restates the line.

## Review Focus

1. **Another model in the environment.** `TTS_MODEL=gpt-4o-mini-tts` or `VOICE_LIVE_MODEL=gpt-live-1` still speaks with `gpt-live-1.1`. Pinned in Task 3.
2. **A private sentence.** `localSpeechOnly` audio is the OS voice, and the secret never appears in a Live event. Pinned in Task 3.
3. **The reader stays silent.** No output audio within 20 seconds is `VoiceProviderError`, not an empty WAV. Pinned in Task 2.
4. **The reader tries to hand the sentence to the app.** A `session.delegation.created` during a read does not send commentary and does not start a turn. Pinned in Task 2.
5. **A custom voice host.** `VOICE_BASE_URL` pointing somewhere other than `https://api.openai.com/v1` does not call `/audio/speech` there. Pinned in Task 3.

### Task 2: A Live reader that says one sentence

**Files:**
- Create: `src/voice/live_speech.ts`
- Test: `tests/unit/live-speech.test.ts`

**Interfaces:**
- Consumes: `connectSocket` and `SocketConnect` from `src/voice/live.ts`. `VoiceProviderError` from `src/voice/errors.ts`. `TtsProvider` from `src/voice/tts.ts`. `STACK.voice`.
- Produces:
  - `export class LiveSpeechProvider implements TtsProvider`
  - `constructor(options: { apiKey: string; baseUrl: string; voice?: string; instructions?: string; speed?: number; connect?: SocketConnect; fetch?: typeof fetch; sleep?: (ms: number) => Promise<void>; now?: () => number })`
  - `readonly name: string` — `"gpt-live-1.1(" + voice + ")"`
  - `readonly supported = true`
  - `readonly baseUrl: string`
  - `readonly voice: string` — default `"coral"`
  - `readonly speed?: number`
  - `synthesize(text: string, input: { language: string; signal?: AbortSignal; pace?: number }): Promise<{ audio: Uint8Array; mimeType: string }>`
  - `mimeType` is always `"audio/wav"`.
  - WebSocket URL is the base URL with `https`→`wss` (and `http`→`ws`) plus `/live/sessions`. No query string.

The body is this protocol. Tests inject `connect` and an instant `sleep`.

1. Connect with `Authorization: Bearer <apiKey>`, `openTimeoutMs: 8000`, `closeTimeoutMs: 1000`.
2. First client event is `session.start` with `store: false`, `model: "gpt-live-1.1"`, `audio: { format: { type: "audio/pcm", rate: 24000 }, output: { voice } }`, `delegation: { type: "client", acknowledgement_delay_ms: 800 }`, and instructions exactly: `You are the voice of Cheongeum. Speak only the text you are told to say, exactly and in full. Do not answer, explain, translate, or delegate.`
3. Wait until `session.started` (skip other events). Handshake HTTP failure becomes `VoiceProviderError` with that status, same as `LiveTranscriber`.
4. Send `session.instructions.append` with `delegation_id: null` and content exactly: `Immediately say the following text exactly and in full, in ${language}, at ${paceText} times normal speed, then stop and say nothing else:\n${text}`. `paceText` is `String(Number(speed.toPrecision(6)))` where `speed` is `min(4, max(0.25, (options.speed || 1) * (pace || 1)))`. When `language === "ko"` and `options.instructions` is a non-empty string, append `\nDelivery: ${options.instructions}`.
5. Concatenate `session.output_audio.delta` payloads in order. They are base64 mono PCM16LE at 24 kHz. On `error`, throw `VoiceProviderError` (status from the same code map `LiveTranscriber` uses, otherwise 502). On `session.delegation.created`, send `session.thinking.append` with `delegation_id` set to that delegation id and content `Finish reading the given text. Do not wait for the application.` Do not send `session.commentary.append`.
6. Remember `started = now()` once. After at least one audio delta, `sleep(700)` with no further `session.output_audio.delta` ends the read. If `now() - started >= 20_000` and no audio has arrived, throw `VoiceProviderError` with status 502. An aborted `signal` closes the socket and rejects.
7. Send `session.close`, close the socket, and return a 44-byte WAV header in front of the PCM: RIFF/WAVE, mono, 16-bit, 24000 Hz.

```ts
it("reads one sentence from gpt-live-1.1 and returns wav", async () => {
  const upstream = scripted(message => {
    if (message.type === "session.start") return [{ type: "session.started", session: { id: "s" } }];
    if (message.type === "session.instructions.append") return [
      { type: "session.output_audio.delta", delta: Buffer.from([1, 2, 3, 4]).toString("base64") },
      { type: "session.output_audio.delta", delta: Buffer.from([5, 6]).toString("base64") },
    ];
    return [];
  });
  const speech = new LiveSpeechProvider({
    apiKey: "sk-test", baseUrl: "https://api.openai.com/v1/", voice: "coral",
    instructions: "천천히", speed: 1.1, connect: upstream.connect, sleep: async () => {},
  });
  const out = await speech.synthesize("안녕하세요", { language: "ko", pace: 0.9 / 1.25 });
  expect(upstream.seen[0]).toEqual(["wss://api.openai.com/v1/live/sessions", { Authorization: "Bearer sk-test" }]);
  expect(upstream.sent[0]).toMatchObject({
    type: "session.start",
    session: {
      model: "gpt-live-1.1", store: false,
      audio: { format: { type: "audio/pcm", rate: 24000 }, output: { voice: "coral" } },
      delegation: { type: "client", acknowledgement_delay_ms: 800 },
      instructions: "You are the voice of Cheongeum. Speak only the text you are told to say, exactly and in full. Do not answer, explain, translate, or delegate.",
    },
  });
  expect(upstream.sent[1]).toMatchObject({
    type: "session.instructions.append", delegation_id: null,
    content: "Immediately say the following text exactly and in full, in ko, at 0.792 times normal speed, then stop and say nothing else:\n안녕하세요\nDelivery: 천천히",
  });
  expect(out.mimeType).toBe("audio/wav");
  expect(Buffer.from(out.audio.subarray(0, 4)).toString("ascii")).toBe("RIFF");
  expect(Buffer.from(out.audio.subarray(8, 12)).toString("ascii")).toBe("WAVE");
  expect(Buffer.from(out.audio.buffer, out.audio.byteOffset + 24, 4).readUInt32LE(0)).toBe(24000);
  expect([...out.audio.subarray(44)]).toEqual([1, 2, 3, 4, 5, 6]);
  expect(upstream.sent.map(m => m.type)).toContain("session.close");
  expect(upstream.isClosed()).toBe(true);
});

it("a read that gets no audio fails instead of returning silence", async () => {
  const upstream = scripted(message => message.type === "session.start" ? [{ type: "session.started", session: { id: "s" } }] : []);
  let calls = 0;
  const speech = new LiveSpeechProvider({
    apiKey: "sk-test", baseUrl: "https://api.openai.com/v1", connect: upstream.connect,
    sleep: async () => {}, now: () => calls++ === 0 ? 0 : 20_000,
  });
  await expect(speech.synthesize("안녕하세요", { language: "ko" })).rejects.toMatchObject({ status: 502 });
  expect(JSON.stringify(upstream.sent)).not.toContain("commentary");
});

it("a delegation during a read does not send the sentence back as commentary", async () => {
  const upstream = scripted(message => {
    if (message.type === "session.start") return [{ type: "session.started", session: { id: "s" } }];
    if (message.type === "session.instructions.append") return [{ type: "session.delegation.created", delegation: { id: "d1", target: "client" } }];
    if (message.type === "session.thinking.append") return [{ type: "session.output_audio.delta", delta: Buffer.from([9, 8]).toString("base64") }];
    return [];
  });
  const speech = new LiveSpeechProvider({
    apiKey: "sk-test", baseUrl: "https://api.openai.com/v1", connect: upstream.connect, sleep: async () => {},
  });
  await speech.synthesize("다음으로", { language: "en" });
  expect(upstream.sent.some(m => m.type === "session.commentary.append")).toBe(false);
  expect(upstream.sent.find(m => m.type === "session.thinking.append")).toMatchObject({

  expect(upstream.sent[1]?.content).not.toContain("Delivery:");
```
