# 청음의 말 이해와 조작 권한

## 말뜻과 권한

청음은 사용자가 요청한 조작을 현재 화면의 항목과 연결하고, 실행 후 확인한 결과를 읽어 준다. 페이지의 제목과 본문은 관찰 자료다. 그 안의 지시나 모델이 제시한 새 목표로 사용자 요청의 범위를 넓힐 수 없다.

## 처리 순서와 담당 코드

| 구분 | 맡은 일 | 담당 코드 |
|---|---|---|
| A. 항상 지키는 제한 | 입력 비식별화, 비밀값 보호, 동의·멈춤, 출처와 입력 칸 확인, 턴당 12회 제한, 근거와 숫자 검증. 승인 뒤에도 대상·화면·유효 시간을 다시 확인한다. 자율 탐색은 최대 10단계·75초이며 같은 동작이 세 번 반복되면 멈춘다. | `session.py:handle_turn`, `gates.py:gate_refusal`, `guard.py:PolicyGuard.check`, `approval.py:recheck`, `verify.py:check_grounding`, `autopilot.py` |
| B. 빠른 길 | 멈춤·진행 상황·명시적인 화면 사진 요청, 대기 중인 승인·거절, 인증 인계 완료, 등록된 명령·사이트 이름을 바로 이해한다. 칸에 맞는 값과 되묻기 답도 로컬에서 처리한다. | `fastpath.py:fast_intent`, `lexicon.py:approval`, `understand.py:Understanding.understand` |
| C. 말뜻 풀이 | 모델이 발화의 조건을 보존해 의도를 정하고 여러 질문을 단계로 나눈다. 모델이 뜻을 알 수 없다고 하면 그 판단을 받아들인다. | `llm_planner.py:plan_with_llm` |
| D. 오프라인 | 모델이 없거나 호출이 실패하면 기존 파서가 명령을 나누고 해석한다. | `rules.py:RuleBasedIntentProvider`, `understand.py:Understanding.understand` |

## 규칙을 추가할 때

새 규칙은 막는 규칙(A)이나 빠른 길(B)일 때만 코드로 만든다. 말뜻 풀이는 planner 프롬프트(understanding/llm_planner.py)에 쓴다.

## 화면 사진으로 메뉴를 찾을 때

청음은 먼저 페이지 글과 브라우저가 읽을 수 있는 조작 항목을 확인한다. 메뉴를 찾는 데 사진이 필요하면 현재 작업과 사이트에 한해 개인정보를 가린 화면 사진으로 확인한다. 로그인, 본인인증, 보안문자 화면이나 개인정보를 가릴 수 없는 화면에서는 사진을 보내지 않는다.

사진에서 찾은 메뉴와 현재 화면의 조작 항목이 하나로 일치하면 청음이 누르기 전에 대상과 조작 권한을 다시 확인한다. 그림에서만 보이는 메뉴는 이름과, 확인할 수 있다면 위치를 말한다. 같은 탭과 사이트에서 메뉴를 직접 연 뒤 '계속해 줘'라고 말하거나 **계속해 줘** 버튼을 고르면 청음이 원래 요청을 이어 간다. 안내 중에 멈추거나 다른 작업을 시작하면 이전 요청은 끝난다.

## 실제 사이트 버튼의 한계

버튼은 현재 화면에서 관찰한 역할과 이름으로 확인한다. 일반 대화에서는 사용자가 지시한 항목을 누르고 실제로 일어난 변화를 확인한다. 공개 자료를 찾는 동안에는 신청·제출처럼 결과를 남기는 조작을 실행하지 않는다. 비밀번호와 본인 인증은 사이트에서 사용자가 직접 입력한다.

## 남은 정리 과제

2026-11-19 규칙 단계 작업에서 넘어온 과제다. 각 과제는 따로 설계한 뒤 진행한다.

1. **해석 호출 하나로 합치기.** 한 턴에서 모델 호출 세 개가 경쟁할 수 있다. `public_task.ts`의 `public_service_decision`, `llm_planner.ts`의 `intent_plan`, `chat.ts`의 `chat_route`를 하나의 구조화 호출로 합친다. 지연을 줄이는 주된 방법이다.
2. **`session.ts`의 분류용 `parseSync` 없애기.** 여덟 곳이 규칙 파서를 분류기로 쓴다. 각 자리를 어휘·빠른 길 판정으로 바꾸거나 해석 결과에서 읽는다.
3. **`rules.ts`를 오프라인 대비로 줄이기.** `demo_scenarios.json`, 등록 명령 시험, 키 없는 시험이 닿지 않는 분기는 측정한 뒤 지운다.
4. **모델이 표시한 위험도.** 자율 탐색 단계 스키마에 `consequential`을 더하고, 코드가 모델 위험도와 규칙 위험도 중 높은 쪽을 쓴다.
5. **`OpenAICompatibleIntentProvider` 정리.** 규칙 우선 해석을 감싸며 `deps.llm`이 없을 때만 쓰인다.
