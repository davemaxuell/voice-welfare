# NVDA로 청음 안내 확인하기

한국어 NVDA와 평소 사용하는 브라우저에서 로컬 연습 세션을 연다. 모의 음성과 준비된 연습 신청서를 사용한다. 시험 전 NVDA 버전, 브라우저 버전, 음성 안내 켜짐·꺼짐, 날짜를 적는다. 표의 각 단계를 두 설정에서 반복하고 실제로 들은 문구와 횟수, 중요한 안내가 끊겼는지를 기록한다.

청음이 말하는 답변과 진행 문장은 대화 기록에도 남는다. 오류는 화면의 경고 영역에 표시한다. NVDA에서 들린 소리와 청음에서 들린 소리를 나누어 기록한다. 한 단계에서 같은 문장을 두 번 들으면 두 번으로 적는다.

| 확인 | 키 입력과 연습 상황 | 들을 내용과 확인할 초점 | 실제 결과 |
|---|---|---|---|
| 답변 | 명령 입력란에서 “장애인연금이 뭐야”를 입력하고 Enter | 답변을 끝까지 들었는지, 같은 답변이 다시 들리는지 | □ |
| 듣기 시작 | 대화 시작을 선택하고 시작 신호가 끝날 때까지 기다림. 5회 반복 | “듣고 있습니다. 말씀하세요.” 1회. 마이크 상태가 덧붙어 반복되는지 | □ |
| 작업 진행 | 연습 신청서에서 세 단계가 있는 작업을 시작하고 기다림 | 각 단계가 바뀔 때 그 단계의 문장 1회. 이전 단계가 다시 들리는지 | □ |
| 마이크 오류 | 시험용 마이크 연결 끊김을 재현 | 연결이 끊겼다는 경고 1회. 진행 중이던 말을 무시하고 필요한 오류를 들을 수 있는지 | □ |
| 실시간 음성 오류 | 모의 실시간 음성 연결 실패를 재현 | 실제 오류 설명 1회 | □ |
| 승인 요청 | 연습 신청서의 입력을 요청. 확인 카드에서 Tab | 요청 내용과 대상, 승인 단추를 찾을 수 있는지 | □ |
| 음성 승인 | 명령 입력란에 초점을 둔 뒤, 모의 음성으로 승인 | 결과를 들은 뒤에도 입력란에서 계속 쓸 수 있는지 | □ |
| 키보드 승인 | 승인 단추로 Tab, Enter | 결과를 들은 뒤 다음 동작에 맞는 곳으로 초점이 가는지 | □ |
| 짧은 알림 | 시험에서 이전 카드의 선택을 전달 | 선택지가 바뀌었다는 안내를 들었는지 | □ |
| 설정 창 | 설정을 열고 모의 작업 상태를 갱신 | 설정 창의 초점이 유지되는지, 뒤쪽 안내가 겹치거나 사라졌는지 | □ |
| 아바타 | 각기 다른 작업 상태 여섯 개를 차례로 전달 | 작업 상태가 달라질 때 한 번씩. 같은 상태를 반복 전송하면 추가 안내가 없는지 | □ |

**시안 선택 기록.** 동일한 한국어 음성이 들어 있는 두 시안을 비교한 운영자의 응답은 “A sounded clearer.”였다. 해당 비교에서는 사용한 NVDA·브라우저 버전이나 사건별 횟수가 보고되지 않았다. 위 표는 최종 후보에서 직접 듣고 채운다.
