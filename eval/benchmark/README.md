# 서비스 비교 벤치마크

**완성된 이음**을 **다른 서비스(범용 AI 대화 서비스, 브라우저 에이전트)**와 같은 기준으로 비교하기 위한 평가 데이터입니다.
`eval/datasets/`(이음 내부 점검용, 자동 채점)와 달리, 여기 과제는 **어떤 서비스에도 똑같이 요청할 수 있게** 사용자 관점으로 썼고, **팀원이 직접 수행하고 채점**합니다.

## 파일

| 파일 | 무엇 |
|---|---|
| `tasks.json` | 과제 34개(서비스 무관, 각 과제에 분야·기능 ①~⑧·사용자 유형 표시): 목표, 그대로 말할 문장, 정답(공식 자료 기준), 확인 항목, 제한 시간 |
| `score.html` | **채점 화면**(더블클릭으로 열기). 서비스를 고르고 과제마다 기록 → 비교표. 팀원 CSV를 불러와 합침 |
| `../benchmark.ts`, `../lib/benchmark-html.ts` | 과제를 고친 뒤 화면 다시 만들기: `npm run eval:benchmark` |

## 과제 구성 (34개 = 5개 분야 × 표 15 기능)

복지만이 아니라 **실생활 공공·정보 업무 5개 분야**로 나누고, 각 과제에 표 15의 **공통 기능(①~⑧)**과 **사용자 유형(공통·노인·장애인·다문화가정)**을 표시했습니다.

| 분야 | 과제 | 기능 |
|---|---|---|
| **세금 신고** (홈택스, 5) | 종합소득세 신고 기한, 연말정산 간소화 메뉴 찾기, 홈택스 화면 이해, 인증서 비밀번호 대행 거절, 연말정산을 영어로 | ④ ③ ② ⑧ 다국어 |
| **민원 접수** (국민신문고, 6) | 민원 신청 화면 찾기 → 칸 설명(쉬운 말) → 말로 작성 → "사흘째가 아니라 일주일째로" 고치기 → 다른 질문 후 재개 → 제출 전 확인 | ③ ⑤ ⑤ ⑥ ⑦ ⑧ |
| **여권 발급** (외교부·정부24, 5) | 처음 발급 준비물, 수수료 찾기, 재발급과 차이 쉽게, 외국인 배우자 자격(중국어), 신청 순서 한 단계씩 | ④ ③ 쉬운 말 다국어 한 단계씩 |
| **뉴스 검색** (포털, 5) | 오늘 주요 뉴스 3개(음성) → 두 번째 기사 요약 → 말하는 중 멈춤 → 천천히 다시 → 영어 3줄 요약 | ① ② ① 반복·속도 다국어 |
| **복지 지원 신청** (복지로, 9) | 금액, 맞춤 찾기, 필요 서류, 근거 없는 질문, 이어 묻기, 신청 화면까지, 입력 항목 뜻, 주민번호 보호, 입력 오류 해결 | ④×4 ⑦ ③ ⑤ ⑧ ⑥ |
| **공통 확인** (4) | 화면을 보지 않고 끝내기(시각), 손 없이 끝내기(지체), 큰 글씨·고대비(노인), 텍스트 표시·상태 표시(청각) | 특화 |

민원 접수는 하나의 흐름(찾기 → 설명 → 작성 → 고치기 → 재개 → 확인)으로 이어져 ⑤~⑧을 실제 작업 속에서 봅니다. 실제 제출 버튼은 누르지 않습니다.
비교표는 서비스별 전체 지표와 함께 **분야별**, **기능별(①~⑧·특화)**, **사용자 유형별** 완료율을 보여 줍니다.

정답의 근거: 복지는 `eval/snapshots/welfare/`(한국사회보장정보원 공식 API 저장본, 2026년 기준). 세금·민원·여권·뉴스는 과제에 적힌 공식 사이트(국세청·홈택스, 국민신문고, 외교부 여권안내 등)를 **테스터가 수행 전·당일 직접 열어 확인**합니다(기한·수수료처럼 바뀔 수 있는 값은 그날 확인한 값이 정답).

## 진행 순서

1. `score.html`을 열고 **진행 규칙** 탭을 읽습니다(같은 문장·새 대화·음성 모드·가짜 민감정보).
2. 위에서 평가할 서비스(이음 / ChatGPT / Gemini / ChatGPT 에이전트 / 기타)를 고르고 버전·모드를 적습니다.
3. 과제마다 파란 칸 문장을 그대로 요청 → 확인 항목 체크, 결과(완료/일부/실패), 정확성, 지어냄·안전 문제, 시간(시작/끝), 주고받은 횟수, 개입 횟수, 메모.
4. 끝나면 **CSV 내려받기** → 팀 공유. 모은 CSV를 **CSV 불러오기**로 합치면 **비교표** 탭에 서비스별 완료율·정확도·지어냄·안전·시간·개입이 나옵니다.

권장: 서비스마다 2명 이상이 수행해 평균을 냅니다. 실제 사이트 과제는 모든 서비스를 같은 날 비슷한 시각에.

## 과제 고치기

`tasks.json`을 고치고 `version`을 올린 뒤 `npm run eval:benchmark`. (버전이 바뀌면 채점 화면의 저장 공간도 새로 시작합니다.)
