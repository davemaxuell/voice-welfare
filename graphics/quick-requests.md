# Quick-choice artwork

The expanded conversation uses three local WebP illustrations. The assets are a [coin purse](../src/cheongeum/web/static/art/pension.webp), a [public service building](../src/cheongeum/web/static/art/site.webp), and a [screen with a voice waveform](../src/cheongeum/web/static/art/screen.webp). The listening and speaking portraits in the same folder are scaled versions of the existing mascot drawings.

The [original transparent sheet](quick-requests.png) is 2172 × 724 pixels. Each WebP is a 160 × 160 export from one 724-pixel square. The source sheet was made with the built-in ImageGen tool using this prompt.

> Create one production UI illustration sprite sheet, wide landscape aspect ratio 3:1. Transparent background. Three small isolated objects for a Korean voice assistant, each centered in its own exactly equal-width third with generous empty gutters and uniform scale. From left to right: a lilac leather coin purse with two satin golden peach coins poking out, a small ivory and peach public service building with triangular pediment and lavender roof, and a muted blue/lilac desktop monitor displaying three bold cream vertical audio wave bars. Match a sophisticated, softly lit 3D clay mascot brand. Simple iconic silhouettes, minimal construction, soft powdery highlights, restrained rich lilac palette, front three-quarter view, no faces. The three objects should read well at 56 pixels each. No lettering, no digits, no text, no logos, no panels or circular backplates, no grid lines, no captions, no floor or ground plane. Only the three objects in a straight equally spaced horizontal row.
